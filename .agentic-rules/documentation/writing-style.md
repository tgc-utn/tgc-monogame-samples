# Documentation writing style

## Capitalization

### Sentence case in titles

Use sentence case (only capitalize first word and proper nouns) in titles and headings.

## Punctuation

### List items

- End all list items with periods, regardless of length or structure.

### Abbreviations in uppercase

Always write abbreviations in uppercase: API, SDK, GPU, CPU, UV, FPS,
HLSL, GLSL, JSON, XML, etc.

## Emphasis

### Use bold sparingly

Overuse of bold makes it lose impact. Use bold only for key terms or important emphasis.
